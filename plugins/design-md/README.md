# design-md

실제 웹사이트 디자인 시스템 DESIGN.md 74종 중 골라 UI를 그 스타일로 만드는 스킬

스킬 본문은 `skills/design-md/SKILL.md`에 있다. 설치는 저장소 루트 README.md(Claude Code: `/plugin install design-md@agent-toolkit`)와 HANDOFF.md(Codex·Gemini·ChatGPT)를 본다. Codex와 Gemini CLI에서는 `scripts/sync-skills`로 스킬 폴더를 `~/.agents/skills`에 복사해 쓴다.

출처와 라이선스는 저장소 루트 NOTICE.md와 LICENSE를 본다. 고친 뒤에는 plugin.json과 marketplace.json의 version을 함께 올린다.
