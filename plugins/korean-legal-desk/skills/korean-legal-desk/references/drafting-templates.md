# 법률문서 템플릿 (모드 B)

모든 템플릿의 `[ ]`는 자리표시자다. 실제 민감번호는 사용자가 최종 파일에 직접 넣는다. 수치(이율·기한)는 SKILL.md 10장 방식으로 재확인한다.

---

## 1. 용역계약서(사업자 간 / 개인 프리랜서 겸용)

```
용 역 계 약 서

[발주자 상호] (이하 "갑")과 [수급인 상호 또는 성명] (이하 "을")은 아래와 같이 용역계약(이하 "본 계약")을 체결한다.

제1조(목적) 본 계약은 갑이 을에게 [용역명]을 위탁하고 을이 이를 수행하는 데 필요한 사항을 정함을 목적으로 한다.

제2조(정의) 본 계약에서 "결과물"이란 을이 본 계약에 따라 갑에게 납품하는 [산출물 종류]를 말한다.

제3조(업무 범위) ① 을의 업무 범위는 별지 1(과업내용서)과 같다.
② 별지 1에 없는 업무는 양 당사자가 서면으로 합의한 경우에만 추가하며, 추가 대금은 별도로 정한다.

제4조(계약기간) 본 계약의 기간은 [YYYY. MM. DD.]부터 [YYYY. MM. DD.]까지로 한다.

제5조(대금 및 지급) ① 용역대금은 금 [금액]원(부가가치세 [포함/별도])으로 한다.
② 갑은 다음과 같이 지급한다. 1. 선급금: 계약 체결 후 [ ]일 이내 [ ]% 2. 잔금: 제7조 검수 완료 후 [ ]일 이내
③ 갑이 지급을 지체하면 지체일수에 대하여 연 [ ]%의 지연이자를 지급한다.
④ (개인 수급인인 경우) 갑은 관계 법령에 따른 소득세 등을 원천징수한 후 지급한다.

제6조(수행 방법) ① 을은 자신의 책임과 판단으로 업무를 수행하며, 갑은 결과물에 관한 요청 외에 을의 근무 시간·장소를 지정하지 않는다.
② 결과물 수정은 [ ]회까지 대금에 포함하며, 이를 넘는 수정은 별도 협의한다.

제7조(검수) ① 갑은 결과물을 받은 날부터 [ ]일 이내에 검수 결과를 서면(전자우편 포함)으로 통지한다.
② 갑이 제1항 기간 내에 통지하지 않으면 검수를 마친 것으로 본다.

제8조(지식재산권) ① 결과물에 대한 저작권 등 권리는 갑이 대금을 모두 지급한 때에 갑에게 이전한다.
② 을이 본 계약 전부터 보유하던 노하우·도구·소스 모듈(이하 "기존 자산")은 을에게 남으며, 을은 결과물 이용에 필요한 범위에서 갑에게 기존 자산의 비독점적 이용을 허락한다.
③ 을은 결과물을 [포트폴리오] 목적으로 표시할 수 있다. 다만 갑이 [ ]일 이내 반대 의사를 표시하면 그러하지 아니하다.

제9조(비밀유지) ① 각 당사자는 본 계약과 관련하여 알게 된 상대방의 비밀정보를 본 계약 목적 외로 사용하거나 제3자에게 공개하지 않는다.
② 이 의무는 본 계약 종료 후 [ ]년간 존속한다.

제10조(손해배상) ① 각 당사자는 본 계약 위반으로 상대방에게 입힌 손해를 배상한다.
② 제1항의 배상 총액은 고의 또는 중대한 과실이 있는 경우를 제외하고 본 계약 대금 총액을 한도로 한다.

제11조(해지) ① 일방이 본 계약을 위반하고 상대방으로부터 [ ]일 이상의 기간을 정한 시정 요구를 받고도 시정하지 않으면 상대방은 본 계약을 해지할 수 있다.
② 해지 시 갑은 해지 시점까지 수행된 업무의 비율에 따른 대금을 정산하여 지급한다.

제12조(권리·의무 양도 금지) 각 당사자는 상대방의 서면 동의 없이 본 계약상 지위나 권리·의무를 제3자에게 양도할 수 없다. 을이 업무 일부를 제3자에게 맡기려면 갑에게 미리 서면으로 알려야 한다.

제13조(통지) 본 계약에 따른 통지는 아래 주소 또는 전자우편으로 한다. 갑: [이메일] / 을: [이메일]

제14조(분쟁 해결) 본 계약에 관한 분쟁은 [ ]지방법원을 제1심 관할법원으로 한다.

제15조(기타) ① 본 계약과 별지가 서로 다르면 본 계약이 우선한다.
② 본 계약은 당사자 사이의 완전한 합의를 이루며, 변경은 서면으로만 한다.

본 계약을 증명하기 위하여 계약서 2부를 작성하여 각자 서명(날인) 후 1부씩 보관한다.

[YYYY. MM. DD.]

갑  상호: [ ]  주소: [ ]  대표자: [ ] (서명)
을  상호/성명: [ ]  주소: [ ]  대표자: [ ] (서명)

[별지 1] 과업내용서
```

작성 메모: 제6조 제1항은 근로자성 다툼을 줄이는 문구지만, 실제 운영이 다르면 효과가 없다고 사용자에게 알린다.

## 2. 내용증명(대금·대여금 청구)

```
내 용 증 명

제목: [용역대금/대여금] 지급 청구

발신인: [성명/상호]  주소: [ ]  연락처: [ ]
수신인: [성명/상호]  주소: [ ]

1. 귀하의 무궁한 발전을 기원합니다.

2. 발신인과 수신인은 [YYYY. MM. DD.] [계약명]을 체결하였고(첨부 1), 발신인은 [YYYY. MM. DD.] 그 의무를 모두 이행하였습니다(첨부 2).

3. 그러나 수신인은 지급기일인 [YYYY. MM. DD.]이 지나도록 대금 금 [금액]원을 지급하지 않고 있습니다.

4. 이에 발신인은 수신인에게 [YYYY. MM. DD.]까지 위 금액을 아래 계좌로 지급할 것을 요청합니다.
   [은행명] [예금주] [계좌번호]

5. 위 기한까지 지급이 없으면 발신인은 부득이 지급명령 신청 등 법적 절차를 진행할 예정이며, 이 경우 지연손해금과 절차 비용도 함께 청구할 수 있음을 알려드립니다.

첨부 1. [계약서 사본] 2. [이행 증빙]

[YYYY. MM. DD.]
발신인 [ ] (서명 또는 인)
```

작성 메모: 사실관계는 증빙으로 확인되는 것만 쓴다. "형사고소하겠다" 같은 협박성 표현, 과장된 금액은 넣지 않는다. 우체국 접수 시 같은 문서 3부.

## 3. 지급명령 신청서 골격

```
지 급 명 령 신 청

채권자 [성명] (주소 [ ])
채무자 [성명] (주소 [ ])

청구금액: 금 [ ]원 / 독촉절차비용: 금 [ ]원

신 청 취 지
채무자는 채권자에게 금 [ ]원 및 이에 대하여 [YYYY. MM. DD.]부터 이 사건 지급명령 정본이 송달된 날까지는 연 [ ]%, 그 다음 날부터 다 갚는 날까지는 연 [ ]%의 비율로 계산한 돈과 위 독촉절차비용을 지급하라는 지급명령을 구합니다.

신 청 이 유
1. [계약 체결 경위]
2. [채권자의 이행]
3. [채무자의 미지급과 독촉 경과(내용증명 등)]
4. 따라서 채권자는 신청취지와 같은 지급을 구합니다.

소 명 방 법
1. [계약서]  2. [이행 증빙]  3. [내용증명 및 배달증명]

[YYYY. MM. DD.]
채권자 [ ] (서명)
[관할] 지방법원 귀중
```

작성 메모: 이율은 약정 이율·법정이율·소송촉진법 이율을 확인해 넣는다. 전자소송(ecfs.scourt.go.kr) 제출 가능. 채무자가 이의신청하면 통상 소송으로 넘어간다.

## 4. 차용증

```
차 용 증

채권자 [성명]  주소 [ ]
채무자 [성명]  주소 [ ]

1. 차용금: 금 [ ]원(₩[ ])
2. 대여일: [YYYY. MM. DD.] (지급 방법: [계좌이체 등])
3. 이자: 연 [ ]% (매월 [ ]일 지급) / 무이자
4. 변제기: [YYYY. MM. DD.]
5. 변제 방법: [채권자 지정 계좌 이체]
6. 기한이익 상실: 채무자가 이자를 [ ]회 이상 연체하거나 [ ]의 사유가 생기면 남은 채무 전액을 즉시 갚는다.
7. 지연손해금: 변제기 다음 날부터 다 갚는 날까지 연 [ ]%

[YYYY. MM. DD.]
채무자 [ ] (서명)
```

작성 메모: 이자율·지연손해금이 최고이자율을 넘지 않는지 확인한다. 보증인을 두면 보증인의 서명과 보증 한도를 서면으로 적는다.

## 5. 비밀유지계약서(상호) 핵심 조항

```
제1조(목적) [검토 목적]을 위하여 교환하는 비밀정보의 보호를 정한다.
제2조(비밀정보) 일방이 상대방에게 제공하는 기술·영업 정보로서 비밀임을 표시하였거나, 성질상 비밀로 다뤄야 함이 분명한 정보.
제3조(제외) 공지된 정보, 제공 전 이미 보유한 정보, 독자 개발 정보, 비밀유지 의무 없는 제3자로부터 적법하게 얻은 정보, 법령·법원 명령에 따라 공개하는 정보(이 경우 사전 통지).
제4조(의무) 목적 외 사용 금지, 필요 인원에게만 공개, 그 인원에게 동일 의무 부과.
제5조(기간) 계약 종료 후 [ ]년. 다만 영업비밀은 영업비밀로 보호되는 동안.
제6조(반환·파기) 요청 또는 종료 시 [ ]일 이내 반환·파기하고 확인서 제공.
제7조(권리 불이전) 비밀정보 제공으로 어떠한 권리도 이전·허락되지 않는다.
제8조(손해배상·금지청구) 위반 시 손해배상, 침해 금지 청구 가능.
```

## 6. 합의서(민사)

```
합 의 서

갑 [ ]  을 [ ]

갑과 을은 [YYYY. MM. DD.] 발생한 [사건의 특정: 일시·장소·내용]과 관련하여 다음과 같이 합의한다.

1. 을은 갑에게 합의금 금 [ ]원을 [YYYY. MM. DD.]까지 [방법]으로 지급한다.
2. 갑은 제1항 금액을 받으면 위 사건에 관하여 을에게 민사상 손해배상 등 일체의 청구를 하지 않는다. [범위를 명확히: 현재 알 수 없는 후유증 포함 여부]
3. 을이 제1항을 이행하지 않으면 본 합의는 효력을 잃고 갑은 원래의 권리를 행사할 수 있다.
4. 양 당사자는 본 합의 내용을 제3자에게 공개하지 않는다(법령상 의무 제외).

[YYYY. MM. DD.]
갑 [ ] (서명)  을 [ ] (서명)
```

작성 메모: 형사사건이면 처벌불원 의사 표시 여부와 범위를 사용자와 따로 확인한다. 미성년자·후견 대상자가 당사자면 법정대리인 동의를 확인한다.
